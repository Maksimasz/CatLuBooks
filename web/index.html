Агент — это отдельная база знаний: своя папка с книгами и своя база внутри неё. Папка создаётся латиницей из названия, поэтому английские версии надёжнее для переноса базы на другой компьютер.

Индексировать — значит прочитать книги и положить их в базу агента. Это может занять минуты; работа идёт в фоне, настройки можно закрыть. Повторная индексация обновляет уже добавленные книги. Удаление книги (🗑) работает на ходу — останавливать сервер не нужно, файл и фрагменты убираются сами.

Каждый ответ чата сохраняется сюда: вопрос, ответ и источники. Нажмите на запись, чтобы развернуть её. Удалить ненужные можно кнопкой 🗑 — они больше не будут занимать место.

Ключи хранятся только на этом компьютере (файл secrets.json в папке проекта) и в интерфейс больше не возвращаются.

Очистка убирает из базы все фрагменты агента, книги на диске остаются. Удаление агента стирает его папку целиком — вместе с книгами, базой и настройками; отменить это нельзя.

Перезапуск поднимает сервер заново (свежий код и настройки). Остановленный сервер поднять обратно можно только на компьютере — командой, которая показана ниже. Останавливать сервер, чтобы что-то удалить из базы, не нужно: удаление в интерфейсе работает на ходу, сервер сам всё закрывает.
